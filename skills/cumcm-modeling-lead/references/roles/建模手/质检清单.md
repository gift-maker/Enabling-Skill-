# 建模手质检清单

## M0：进入编程前

- [ ] 已读完题目和全部附件，输入文件保持只读或有明确版本。
- [ ] 已建立全部子问的输入输出和依赖图。
- [ ] 已区分题目事实、数据发现、领域依据、建模假设、设计选择和未知项。
- [ ] 每问的系统边界、结论目标、输出单位和评价口径明确。
- [ ] 集合、下标、输入、参数、决策变量、状态变量、随机变量和输出定义完整。
- [ ] 每条关键假设有必要性、依据、失效影响和检查方式。
- [ ] 每个核心方程有现实含义、来源、量纲、代码接口和失效条件。
- [ ] 每条约束有来源并区分硬/软、逐期/累计、个体/总体及变量域。
- [ ] 目标函数与现实目标一致，多目标权衡有依据或预设敏感性分析。
- [ ] 参数来源和可辨识性已检查。
- [ ] 已比较主方案、审计基线、强备选、降级保留和淘汰方案，理由与本题直接相关。
- [ ] 已预先定义验证、失败判据和降级条件。
- [ ] 每个递进子问题已与上一问比较并重新识别结构；第三问优先检查，但未硬编码 NP-hard。
- [ ] 建模手能独立复述逻辑链并回答“为什么这样建模、什么证据会推翻它”。

## 实现回审

- [ ] 代码变量、索引、目标、约束、边界和单位与模型合同一致。
- [ ] 实现引入的新假设、近似、默认参数和阈值已回写并确认。
- [ ] 小样例或可手算特例已经跑通，结果方向和数量级合理。
- [ ] 求解算法与数学结构匹配，停止条件、随机种子和状态码明确。
- [ ] 启发式算法已有小规模精确解、上下界、多起点或多种子证据之一。

## 结果回审

- [ ] 所有关键数值来自真实运行，未收敛或不可行输出没有进入结论。
- [ ] 优化解已回代全部硬约束；预测、评价、统计和仿真使用题型匹配验证。
- [ ] 已按题意从任务增益维度池中选取与主方案角色相关的维度，没有机械执行八项全审。
- [ ] 预测指标未提升时没有直接淘汰：有额外价值则降级保留并收紧表述，全部主要维度均无实质增益时才淘汰回退。
- [ ] 轻微但不稳定的增益仅作为备选或情景分析；统计显著但无实际决策或题意价值时没有升级为主模型。
- [ ] 后一问新增变量、因素、约束、误差或决策目标时，扩展模型已实际回答新增要求，没有因交叉验证未提升而重复上一问。
- [ ] 预测只作为决策输入层时，已用决策质量、风险、约束满足、稳健性和不确定性传播评价完整方案。
- [ ] 敏感性、不确定性和随机波动得到适当检查。
- [ ] 前问到后问的单位、索引、时间尺度和误差传播一致。
- [ ] 每个结论有对应结果证据，因果、外推和推广没有超出模型支持范围。
- [ ] 结果变化后，下游问题、表格、图和摘要已同步检查。
- [ ] AI 参与、人工修改和核验已如实记录。

## 冻结与解冻

- [ ] 当前问已完整回答，核心假设无明显冲突，至少完成一种合适的样本外或稳健性验证。
- [ ] 所有硬约束满足，最强备选没有足以改变主结论的明显优势。
- [ ] 结果可复现，关键数值已经独立回代检查；满足以上条件后已冻结并进入下一问。
- [ ] 冻结后未因轻微问题、额外敏感性、边际改进、更多 CV/Bootstrap/种子或备选模型自动解冻。
- [ ] 解冻仅由数据泄漏、目标定义错误、核心约束违反、明显计算错误、模型结构失效或可能改变主要结论的问题触发。
- [ ] 新增验证若预计不改变模型选择、主要结论、分组、排名或最终决策，已停止并记为局限或附录。

独立 Agent 质检是增强项；不可用时由未参与该部分的队员交叉审核并记录范围，不因缺少 Subagent 自动把可信结果判为失败。
