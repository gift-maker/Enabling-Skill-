# 提交前阶段：AI 工具使用声明与详情 PDF

## 定位

本阶段只在当届全国、赛区或提交系统明确要求，且本次解题实际使用了 AI 工具时执行。它不参与建模计算，不得阻塞前面的结果产出。

本阶段完成两件事：

1. 核对论文中参考文献之前的 AI 工具使用声明；
2. 依据真实 `ai_usage_log.md`，生成并编译 `AI使用报告-LaTeX/`，输出 `AI工具使用详情.pdf` 作为支撑材料。

核心口径：核心建模与问题分析由参赛队主导；AI 参与内容必须逐项人工审查、重跑、修改或弃用。不得虚构工具、时间、提示词、人工动作，也不得用“未使用”掩盖实际使用。

## 触发与前置

触发时机：完整论文和摘要定稿、正式提交前。以当届官方原文为准，不把本文件中的示例口径当成永久规则。

前置输入：

- `PROJECT_ROOT/ai_usage_log.md`，记录实际环节、时间、工具、提示词摘要、处置和核验；
- `PROJECT_ROOT/完整论文-LaTeX/` 与真实编译的 `完整论文.pdf`；
- `results/复现清单.json`、代码、结果和支撑材料清单；
- 用户确认的工具名称/版本、比赛名称和适用时间范围。

如果留痕缺失或为空，先停止并补齐真实记录，禁止凭印象补造。

## 执行流程

1. **核对官方口径**：确认当届声明文案、详情材料格式、提交位置和时间要求。
2. **回读事实源**：读取 `ai_usage_log.md`、论文源码、复现清单和结果目录，整理环节—文件—核验关系。
3. **生成 LaTeX 报告**：复制报告模板到 `AI使用报告-LaTeX/`，填入真实工具和环节记录；提示词只写脱敏摘要，不附原始对话全文。
4. **一致性审计**：运行 `ai_report_audit.py`，确保声明、留痕、报告和文件位置一致。
5. **编译并审核**：使用 XeLaTeX/latexmk 编译为 `AI工具使用详情.pdf`，检查页码、字体、隐私信息和文字内容；用户审核通过后冻结。
6. **并入支撑材料**：把 PDF 列入附录支撑材料清单，并回查论文中的声明和报告用途一致。

## 报告最低结构

- 官方 AI 使用声明及适用口径；
- 所用工具名称、版本/型号、提供方入口；
- 使用环节和具体目的；
- 提示方式与脱敏摘要；
- AI 输出的采纳、修改、弃用和重跑；
- 参赛队的模型决策、程序复核、结果验证和定稿贡献；
- 对应的代码、结果、LaTeX 文件和核验路径。

核心建模、问题分析和结论必须写明“参赛队主导确定，AI 提供候选或辅助，结果经人工审查和实际运行核验”。

## 命令参考

```powershell
# 一致性审计
python "<SKILL_ROOT>/references/AI使用报告/scripts/ai_report_audit.py" "<PROJECT_ROOT>" `
  --report "<PROJECT_ROOT>/AI使用报告-LaTeX/main.tex" `
  --paper "<PROJECT_ROOT>/完整论文-LaTeX/main.tex"

# 使用 LaTeX 工具真实编译（具体模板和后端以项目配置为准）
python "<SKILL_ROOT>/tools/latex/scripts/latex_paper.py" build `
  "<PROJECT_ROOT>/AI使用报告-LaTeX/main.tex" `
  --engine xelatex `
  --publish "<PROJECT_ROOT>/AI工具使用详情.pdf"
```

PDF 必须由当前源码真实编译得到；源码、PDF 或留痕变化后重新审计和编译。
