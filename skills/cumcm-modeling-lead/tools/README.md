# 工具链（按需加载）

本技能把工具按任务拆分，优先服务数据读取、建模计算、结果复现和 LaTeX/PDF 交付：

```text
tools/
  pdf/          题目 PDF 读取、表格提取、转图
  xlsx/         Excel 读取与必要的公式重算
  docx/         用户明确选择 Word 时的文档生成与检查
  latex/        LaTeX 论文初始化、编译、校验与模板
  paper_search/ 双引擎论文搜索（OpenAlex + AnySearch）
  drawio/       必要时生成技术路线/流程图等非数据图
  drawio/scibox-diagram/
                论文级流程图模板
```

## 使用规则

1. 使用任一工具前，实际读取对应 `SKILL.md`；它会在需要时继续路由到同目录的 `TOOL_GUIDE.md`。
2. 优先调用工具自带脚本和模板，禁止为了省事手写替代实现。
3. 工具服务于计算和结果交付，不得让非关键排版阻塞建模运行。
4. 缺少依赖时先报告具体阻塞；若影响计算，按阶段流程中的备用路线降级；不得把未验证结果当作完成。
5. 工具默认只写入题目项目目录，技能目录保持只读。

## 与 `scripts/` 的分工

- 通用数值/结果脚本：数据剖析、绘图风格、图表审计、论文门禁、复现清单位于本技能 `scripts/`。
- 格式和输入工具：PDF、Excel、LaTeX、论文搜索和流程图位于 `tools/`。
- 默认只交付建模结果包；用户明确要求论文整合时只维护 LaTeX，AI 使用详情按当届规定生成。
