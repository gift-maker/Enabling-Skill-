# AI 使用报告：一致性自检清单

每项记录核对结果和证据位置；存在 FAIL 不得提交。

## 一、论文声明 ↔ 报告

- [ ] 论文源码中 AI 使用声明位于参考文献之前，位置和文案符合当届官方规则；
- [ ] 声明的“是否使用”与报告一致；
- [ ] `ai_usage_log.md` 有实际使用记录时，声明没有写成“未使用”；
- [ ] 声明用途与报告综述、工具清单和分环节记录不冲突。

## 二、留痕 ↔ 报告

- [ ] `ai_usage_log.md` 覆盖实际参与的题意、数据、建模、代码、图表和写作环节；
- [ ] 报告每个“使用”环节都能找到对应留痕；
- [ ] 日期、时间段、工具名称和版本真实且一致；
- [ ] 提示词摘要为脱敏概括，处置写明采纳、修改、弃用或重跑；
- [ ] AI 参与过候选建模或实现时，没有把该环节表述为完全未使用或完全独立推导。

## 三、报告 ↔ 论文/代码/结果

- [ ] 报告中的章节、脚本、结果文件和图表路径真实存在；
- [ ] 方法名、模型名和关键结果与 LaTeX 正文一致；
- [ ] `results/复现清单.json` 能支撑报告中的复现和核验描述；
- [ ] 附录支撑材料清单按当届要求列出 `AI工具使用详情.pdf`；
- [ ] PDF 由当前 `AI使用报告-LaTeX/` 源码真实编译得到。

## 四、隐私与合规

- [ ] 没有姓名、学号、学校、赛区、账号、密钥、token、内网地址或未公开数据；
- [ ] 没有原始对话全文，只有脱敏摘要；
- [ ] 没有虚构工具、时间、环节或人工动作；
- [ ] 练习记录没有冒充正式竞赛记录；
- [ ] 核心建模和问题分析如实写为参赛队主导，并说明人工审查和实际运行核验。

## 五、自动审计与 PDF 检查

- [ ] 运行：

  ```powershell
  python "<SKILL_ROOT>/references/AI使用报告/scripts/ai_report_audit.py" "<PROJECT_ROOT>" `
    --report "<PROJECT_ROOT>/AI使用报告-LaTeX/main.tex" `
    --paper "<PROJECT_ROOT>/完整论文-LaTeX/main.tex"
  ```

- [ ] 审计退出码为 0；所有 WARN 已人工确认并记录理由；
- [ ] `AI工具使用详情.pdf` 已由 LaTeX 真实编译并逐页检查，无乱码、越界、隐私泄漏或错误文件名；
- [ ] 源码、留痕、PDF 和支撑材料清单最后一次校验后未再被改动。
