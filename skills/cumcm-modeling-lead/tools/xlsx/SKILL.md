# Excel attachment support

Read [TOOL_GUIDE.md](TOOL_GUIDE.md) before using this directory's scripts. Preserve the original workbook, inspect sheet names, dimensions, formulas, units, missing values and merged cells, and record whether formulas were recalculated. Write derived data only to the problem project directory.
