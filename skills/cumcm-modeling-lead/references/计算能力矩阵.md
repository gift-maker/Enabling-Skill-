# 计算能力矩阵

模型路线确认前，对候选方案执行最小导入或求解测试。`requirements.txt` 只覆盖基础数据、统计与绘图环境；以下能力按题目需要安装，不因算法资料中出现名称就假定可用。

| 能力 | 常用实现 | 赛前/赛时检查 |
|---|---|---|
| 数据契约 | Pandera；小项目可用显式断言 | 字段、类型、缺失、范围、唯一性、时间顺序 |
| 符号接地 | SymPy | 表达式等价、求导、解回代；不能替代现实有效性判断 |
| 单位与不确定性 | Pint、uncertainties | 单位转换、量纲、误差传播、数量级 |
| 敏感性分析 | SALib；简单任务使用单因素扰动 | Morris/Sobol 样本量、参数范围、随机种子 |
| 线性与整数规划 | `scipy.optimize.milp`、PuLP/CBC、HiGHS | 最小可行模型、状态码、整数变量、时限 |
| 约束规划与调度 | OR-Tools CP-SAT | 求解器导入、最小排程、状态码 |
| 凸优化 | CVXPY + 可用后端 | DCP 结构、后端、最小问题 |
| 图与网络 | NetworkX | 最短路/网络流小实例 |
| 统计与时序 | statsmodels | 回归、ARIMA/状态空间最小拟合 |
| 树模型 | scikit-learn；按需 XGBoost/LightGBM | 版本、训练、预测和特征接口 |
| 多目标优化 | pymoo 等 | 最小 Pareto 示例、终止条件和种子 |
| 深度学习 | PyTorch/TensorFlow | 仅在数据量、环境和时间支持时启用 |
| MATLAB | MATLAB + 实际工具箱 | `version`、`ver` 和最小脚本 |

为最终候选记录：是否安装、版本、最小测试命令、退出状态、预计全量时间/内存和降级方案。环境不可用时切换成熟可复现路线，不在比赛中临时维护复杂依赖。
