# 优秀论文资料路由

本文件解决两件事：让已有优秀论文提炼真正进入模型选型，同时避免把 93 篇摘要和整份语料报告一次性加载进上下文。优秀论文只用于生成、修正和淘汰候选，不是标准答案。

## 一、四类资料分别什么时候读

| 资料 | 主要用途 | 读取时机 |
|---|---|---|
| `摘要写作/摘要汇总.md` | 93 篇优秀摘要中的题目结构、模型组合、求解和验证线索 | 完整赛题在第三步冻结主路线前；这是模型选型阶段的主要本地语料入口 |
| `优秀论文语料分析报告.md` | 2021–2025 跨年份的章节结构、题型习惯、验证和证据组织统计 | 需要核对跨年方法呈现或题型共性时读取对应小节；不代替逐篇摘要 |
| `优秀论文写法指南.md` | 把冻结结果写成论文各部分 | 第七步写对应章节前读取对应章节 |
| `摘要写作/摘要写作方法论.md` | 摘要结构、起草和逐数字核验 | 正文与结果冻结后、写摘要前读取 |

外部学术检索使用 `tools/paper_search/SKILL.md`。本地优秀论文检索与外部学术检索用途不同：前者发现竞赛中的可迁移路线和验证组织，后者核验领域机理、参数依据和方法适用条件。

## 二、模型选型阶段的最小检索闭环

先独立完成题意、数据结构和第一版模型合同，再执行以下步骤：

1. 在 `摘要写作/摘要汇总.md` 中依次搜索：同年同题编号、应用对象或领域词、关键数据结构词、由本题独立推出的方法词。
2. 数据结构词优先使用能改变模型适用性的词，例如重复测量、删失、时空相关、整数约束、多目标、类别不平衡、网络、排队、微分方程或鲁棒优化；不要只按 A/B/C/D/E 题号机械映射模型。
3. 阅读命中的完整摘要，而不只读搜索命中行。通常精读最相近的 2–4 篇；应急保底时可缩减为 1–2 篇。没有有效命中时记录查询词和“无可迁移命中”。
4. 把实际影响写入 `全队建模记录.md`：

```text
语料编号：
与本题相同的结构：
可迁移的方法或验证：
不可照搬的参数、假设或结论：
对候选排序的影响：保留 / 改造 / 淘汰 / 无影响
```

5. 候选集中至少保留一个从当前题意、数据或数学原理独立推出的强候选，防止对优秀论文路线过拟合。

## 三、路线确认门

正式完整赛题冻结主路线前，`全队建模记录.md` 必须满足以下之一：

- 已记录本地检索词、精读摘要、可迁移点、不可照搬处以及对候选排序的实际影响；
- 已记录没有有效命中或比赛进入应急保底，并说明为什么继续检索不会改变当前决策。

环境检查、附件审查和廉价数据 smoke test 不必等待语料检索；但不得在完全没有上述记录时宣称主路线已经完成论证。单个公式问答、普通代码调试、只改排版或用户明确限制为局部任务时，不强制执行完整检索闭环。

## 四、停止条件

检索服务于决策，不做无边界综述。出现下列任一情况即可停止：

- 新摘要不再增加候选、改变假设或补充验证方法；
- 已获得主方案、强备选和廉价审计基线的充分比较依据；
- 剩余时间要求进入小闭环或应急保底；
- 命中论文与本题在目标、数据结构或约束上缺乏实质对应。

停止后保留检索词和裁决，不复制摘要中的数值、参数、阈值、分组或性能作为本题结果。
