# 论文与图表证据协议

## 写作入口

论文写作只接受以下输入：

- 建模手确认的模型合同；
- `paper_ready` 的结果登记项；
- 通过视觉检查且有源数据的图表；
- 已核验的题面事实、附件信息和文献；
- 明确的结论边界和风险说明。

讨论中的候选、旧结果、聊天数字和未核验引用不得进入摘要、结论或主结果表。

## Claim 合同

每个高价值论文主张必须登记：

- `claim_id`；
- 对应子问；
- 主张文本；
- 数值、单位、分母、基线和场景；
- 支撑它的 `result_id`、`figure_id`、公式或来源；
- 证据状态；
- 适用边界；
- 论文位置。

摘要只能压缩正文中已经成立的 Claim，不能产生新结论。结论不能把“相关”“候选”“近似可行”“情景结果”加强为“因果”“最优”“严格可行”或“普遍规律”。

## 图表合同

正文图用于证明模式、机制、比较、权衡或稳健性；精确数值优先使用表格。每张正文图必须具有：

- 唯一 `figure_id` 和所支持的 `claim_id`；
- 源数据文件和生成脚本；
- 单位、场景、基线和不确定性表达；
- 图注、图后一句结论和风险边界；
- 最终尺寸可读性检查；
- PNG 预览及 SVG/PDF 等可复现输出（适用时）。

不得为了美观删除异常点、连接缺失观测、截断坐标夸大差异、用颜色作为唯一编码，或将单次随机仿真截图作为正式证据。

## 一致性检查

终稿逐项比较摘要、正文、表格、图片、结论、附录和支撑材料中的：

- 数值、符号、正负号和有效位数；
- 单位、分母和时间/空间尺度；
- 基线、情景、样本范围和可行性状态；
- 模型名称、参数定义和约束口径；
- Claim、Result、Figure 与 Run 的引用关系。

冲突时回到权威 Run 和 Result；不得凭印象选一个数字，也不得取平均值。

## 写作边界

论文助手可以组织段落、统一符号、改善衔接、生成 LaTeX 和修复编译错误。它不能：

- 增加未确认的模型或假设；
- 创造新结果、参数、引用或实验；
- 改变冻结结果的数值和单位；
- 用更强措辞掩盖验证不足；
- 将内部 AI 参考稿直接视为队伍终稿。

正式提交前重新核验当届规则、匿名要求、支撑材料和 AI 使用披露。
