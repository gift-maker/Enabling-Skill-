# 建模设计理论

## 问题与模型匹配

| 问题结构 | 模型方向 | 必查条件 |
|---|---|---|
| 约束下求最优 | 线性、整数、非线性、鲁棒或多目标优化 | 变量类型、可行域、目标和约束 |
| 随时间变化 | 时间序列、状态空间、机器学习预测 | 时间顺序、平稳性、外生变量和回测 |
| 多指标排序 | 统计降维、组合赋权、效率评价 | 指标方向、相关性、权重依据和稳健性 |
| 网络关系 | 最短路、网络流、复杂网络 | 节点、边、方向、权重和连通性 |
| 不确定系统 | 概率模型、蒙特卡洛、随机或鲁棒优化 | 分布依据、场景和风险指标 |
| 模式识别 | 聚类、分类、集成学习 | 标签、样本代表性、数据泄漏和验证集 |

## 设计原则

1. **充分性**：覆盖题目目标、关键约束和关键数据。
2. **可证伪性**：预先定义会让模型失败的检验。
3. **可实现性**：公式、算法与 Python/MATLAB 工具一致。
4. **可追溯性**：参数、阈值和假设都有来源。
5. **创新性**：避免直接套用常见简单模型；创新点必须能映射到具体实现和验证。

复杂度由问题结构、数据和验证要求决定。

每个递进子问题都与上一问比较并重新识别结构，第三问优先检查。新增离散决策、组合约束、资源配置、时序、风险或不确定性时，重新判断是否已由统计/预测升级为决策/组合优化或“统计 + 决策优化”。第三问不等于 NP-hard；只有出现相应结构时，才提高 MILP、MINLP、CP-SAT、动态规划、网络优化和成熟启发式的优先级。

## 模型数量

模型数量由题目结构和证据价值决定。默认先确定主方案并完成最小纵向闭环，再建立一个低成本、可靠的审计基线；只有在改善样本外表现或稳定性、增加机制/变量作用解释、提升决策或风险分层、处理新约束或不确定性、回答递进子问题新增要求，或提供独立验证时才增加其他模型。串联模型用于完成必要阶段，不为数量机械拆分或合并。

预测性能没有改善不等于复杂模型没有价值。存在额外解释、决策、约束或稳健性价值时，模型可降级为扩展方案；轻微但不稳定的增益作为备选或情景分析；相关主要维度均无实质增益时才淘汰并回退基线。统计显著性本身不足以把模型升级为主模型。

复杂度审查把预测价值、题意回答能力、解释价值、决策价值、风险分层、约束满足、稳健性和不确定性处理作为候选维度池，只按题意选取相关维度，不机械执行八项全审。预测模型若只是优化模型的输入层，CV、RMSE、NLL、Brier 等指标只能评价预测层；完整路线还要评价与最终任务相关的目标、可行性、风险或决策稳定性。

灵敏度分析、残差分析、消融实验、交叉验证和可视化属于验证方法，不单独计作模型。

物理问题按模型族而不是公式版本计数。同一物理机制、同一组核心状态变量和控制方程，在不同近似阶次、反射次数、边界简化或数值精度下的表达，属于一个模型族。例如，两光束干涉与多光束干涉若只是同一干涉机制的精度展开，计为一个模型；若引入不同传播机理或新的耦合状态方程，才另计模型。

多个模型得到相近结论并不自动构成保留或删除理由，应根据研究目的、方法差异、运行成本和证据价值决定。

## 组合方式

| 方式 | 条件 | 示例 |
|---|---|---|
| 串联 | 前一模型输出是后一模型必要输入 | 需求预测 → 库存优化 |
| 并行 | 需要比较不同假设或方法 | 统计模型与机器学习模型回测 |
| 主模型加验证 | 一个模型回答问题，另一模型验证边界 | 优化模型 + 仿真验证 |

## 验证设计

验证方式根据模型选择，可包括留出集、滚动回测、残差诊断、约束可行性、最优性界、稳定性、灵敏度、消融实验和外部数据对照。检验阈值必须写明依据。

验证达到足以支持模型选择和主要结论即可。若新增验证预计不会改变模型选择、主要结论、分组、排名或最终决策，应停止并优先完成其余子问题。
