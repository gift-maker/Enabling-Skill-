# 模型选型树

本文件用于根据问题结构扩展和初筛**完整模型方案**，不直接决定主模型。先读取 [模型决策中心](模型决策中心.md)。最终选择必须回到现实目标、数据结构、参数可辨识性、验证证据、计算预算和建模手裁决。

## 第一层：任务目的

先区分描述、解释、预测、评价、决策和机理。一问可包含多个模块，例如“预测需求后优化库存”；应先定义模块接口和误差传播，不能把算法名称直接串联。

## 第二层：结构检查

| 结构 | 必查问题 |
|---|---|
| 时间 | 是否有趋势、季节、滞后、结构突变或只能按时间验证 |
| 空间/网络 | 是否存在邻接、距离、方向、连通或空间相关 |
| 随机性 | 不确定性来自观测、参数、未来情景还是过程 |
| 数据生成 | 样本是否独立；是否重复、分组、删失、选择偏差或类别不平衡 |
| 变量 | 是观测量、潜变量、控制量、状态量还是决策量 |
| 关系 | 有无守恒、单调、容量、先后、几何或物理边界 |
| 参数 | 当前数据能否识别参数；自由度是否受样本支持 |
| 结论 | 需要点估计、区间、排名、概率、方案还是机制解释 |
| 代价 | 哪种错误或不可行后果更严重 |
| 跨问 | 输出怎样进入后问，单位和不确定性怎样传递 |

## 第三层：模型族与组合结构

| 核心结构 | 可扩展的模型族 | 进入候选前的条件 |
|---|---|---|
| 连续或整数决策、明确约束 | LP/MIP、凸或非线性规划、动态规划、网络流、CP-SAT | 先写变量、目标、约束和变量域 |
| 多目标冲突 | 分层优化、约束法、归一化加权、Pareto | 说明目标单位、冲突和偏好依据 |
| 纯时间序列 | 朴素基线、指数平滑、ARIMA、状态空间 | 按时间回测并检查结构变化 |
| 有解释变量的预测 | 线性/正则回归、树、提升树、核方法、适合规模的时序模型 | 防泄漏；验证集调参；报告样本外误差和不确定性 |
| 多指标评价 | 直接指标、PCA/因子、AHP、熵权、TOPSIS、DEA、模糊评价 | 先定义价值标准、方向、冗余和权重含义 |
| 分类或分群 | 逻辑回归、树、提升树、SVM、聚类、混合模型 | 标签和样本代表性明确；验证与现实解释成立 |
| 网络与路径 | 最短路、匹配、生成树、网络流、TSP/VRP | 明确节点、边、方向、权重和容量/时间窗 |
| 动态机理 | 代数/差分/微分方程、状态空间、Markov、系统动力学 | 说明守恒、边界、参数识别和收敛 |
| 随机系统 | 随机过程、仿真、随机/鲁棒优化 | 明确不确定性来源和风险度量 |

在模型族基础上检查合法组合：串联、并联比较、集成预测、分层、机制与数据融合、评价与优化衔接。组合的每个模块必须有必要性、清楚接口和可验证增益。

灰色预测只在序列结构和检验支持时进入；熵权反映样本区分度，不等于现实重要性；蒙特卡洛只在随机性、风险传播或数值积分确有作用时使用。

## 第四层：广搜与实验短名单

AI 的概念搜索不限定在少数预设算法中，应覆盖结构不同的单模型和组合方案。随后按以下标准淘汰：

1. 是否解决本题的关键结构或基线缺陷；
2. 假设是否符合数据生成过程；
3. 参数能否识别；
4. 能否设计无泄漏、可推翻的验证；
5. 是否满足现实硬约束和错误代价；
6. 是否能在比赛时间内稳定复现；
7. 复杂度是否带来可测量收益；
8. 是否有假设不同的备选和降级路线。

进入实际原型的通常是少数有区分价值的完整方案，而不是机械实现所有想到的算法。优秀论文用于扩展候选和学习验证，不能因出现频率提高排序。

## 第五层：题型验证

- 预测/分类：正确对象上的切分、样本外误差、阈值、校准、类别不平衡、稳定性和基线；
- 优化：硬约束回代、可行性、上下界、最优性状态和多起点；
- 评价：指标方向、价值含义、冗余、权重与排名敏感性；
- 仿真/机理：守恒、边界、量纲、步长或网格收敛；
- 统计推断：设计、分布、相关性、效应量、区间和稳健性；
- 聚类：稳定性、现实解释和外部验证。

评价指标、阈值和错误代价由现实任务与证据确定。任何自动排行只产生推荐，不能替代建模手冻结。
