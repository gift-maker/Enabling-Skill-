# 模型决策中心

本文件是建模阶段的主入口。AI 与全队共同构造、反驳、比较和修改完整模型方案；AI 只有建议权，建模手拥有最终裁决权。

## 选择对象

不要把算法名称等同于模型。完整方案按题目需要包含：

```text
现实对象与边界
→ 数据单位和状态/标签
→ 输入、变量与参数
→ 数学关系、目标与约束
→ 求解或预测算法
→ 决策规则与阈值
→ 不确定性和误差传播
→ 解释方法
→ 验证与失败条件
```

模型可以是单一结构，也可以是有清楚接口的串联、并联、集成、分层、机制与数据融合或评价—优化组合。

## 从结构生成方案

先回答：

1. 任务是描述、解释、预测、评价、决策还是机理；
2. 对象、时间、空间和输出形式是什么；
3. 数据是否有时间、空间、网络、分组、重复、删失、类别不平衡或选择偏差；
4. 哪些是硬约束，哪些是需要检验的假设；
5. 哪种错误或代价最重要；
6. 需要点估计、区间、概率、排名、方案还是机制解释；
7. 前后问怎样传递数值、单位和不确定性。

AI 可以广泛思考可能方案，不预设只能从某几个算法中选择。实际原型阶段由建模手根据信息增益、结构差异、计算预算和验证能力选择少数方案，不为凑数实现大量同类算法。

## 候选方案卡

每个候选使用同一结构：

```text
方案名称：
现实角色：
完整结构：
输入与输出：
解决的关键缺陷：
核心假设与约束：
参数如何取得：
为什么进入候选：
相对简单基线的预期增益：
如何公平验证：
什么证据会淘汰：
失败后的降级路线：
计算和复现成本：
当前状态：
```

状态只使用：构想、候选、已跑通、暂定推荐、待建模手裁决、已冻结、已解冻、已淘汰。

候选至少包含廉价审计基线和一个假设不同的强方案。题目结构支持组合模型时，必须说明模块接口和误差传播；单模型已经足够时，不为“创新”强行组合。

## AI 双向论证

AI 对每个候选同时给出支持和反驳：

- 哪个问题结构支持它；
- 哪项数据事实可能违背它；
- 它比基线多解决了什么；
- 它可能在哪里泄漏、过拟合、不可识别、不可行或不稳定；
- 哪个最小实验能够区分它与竞争方案；
- 达到什么条件才保留，出现什么条件必须淘汰。

证据不足时使用条件式推荐，不用模型常见、名称高级或论文中出现过替代证据。

## 组合模型检查

| 结构 | 必须检查 |
|---|---|
| 串联 | 前一模块输出如何进入后一模块；单位、范围与误差如何传递 |
| 并联比较 | 数据、切分、指标和计算预算是否一致 |
| 集成预测 | 基模型误差是否互补；权重是否在独立验证中确定；是否稳定优于最强单模型 |
| 分层模型 | 数据是否确有层级；各层参数是否可识别 |
| 机制与数据融合 | 机制规定什么，数据估计什么；两部分是否重复或冲突 |
| 评价与优化 | 评价分数如何进入目标或约束；权重不确定性是否传播 |

禁止无接口地串联算法、平均多个弱模型后声称稳健、把求解器当数学模型，或用评价分数替代真实决策目标。

## 建模手初审

进入实验前呈现：

```text
正在决定：
问题结构：
AI生成的完整方案：
建议进入实验的方案及理由：
建议暂缓或淘汰的方案及理由：
现实目标和错误代价：
统一比较口径：
尚未确认的假设：
建模手裁决：待确认
```

建模手可以自然语言增删模块、改变目标或约束、加入组合方案、指定强备选。AI 将修改转成可执行的模型合同，并说明影响范围。

## 公平实验

比较保持相同的数据口径、评价对象、训练验证边界、指标定义和适当的计算预算。按题型检查样本外表现或可行性，并报告波动、区间、阈值、敏感性、解释性、运行成本和相对基线增益。

AI 输出：

```text
当前推荐：
推荐依据：
相对基线的增益：
最强竞争方案：
反对当前推荐的证据：
推荐会在什么目标或条件下改变：
未完成的验证：
AI建议：保留/继续验证/退回修改
建模手裁决：待确认
```

指标第一只能成为推荐证据之一。差异没有稳定超过验证波动、关键约束不满足或复杂度没有可测量收益时，优先保留更简单、稳定和可解释的方案。

## 人工冻结门

只有建模手明确确认后，记录：

```text
冻结方案：
保留基线与强备选：
冻结依据：
关键假设：
适用边界：
建模手裁决：通过
模型状态：已冻结
允许正式预测/求解：是
允许写入论文和终稿图：是
```

自动选模器、排行榜或代码变量 `best_model` 不得替代这一步。没有人工冻结时，结果一律标为候选。

## 实时修改与回退

新数据、验证失败、后问接口冲突或建模手改变目标时，记录：

```text
修改内容：
修改原因和证据：
影响的问题与模块：
需要重跑的代码和实验：
失效的旧结果、图表和文字：
保留的对照版本：
修改后的验证：
模型状态：已解冻/待确认
```

退回到受影响的最早阶段，不无关地从头重做。旧结果可用于比较，但必须标记失效，不能继续进入论文。

## 全队复述门

冻结前，全队应能不用 AI 回答：

1. 为什么这个完整方案适合现实问题；
2. 每个模块的输入、输出和接口；
3. 关键假设和约束来自哪里；
4. 它相对基线解决了什么；
5. 哪些证据支持，哪些证据反对；
6. 什么情况下应换成强备选；
7. 结论能够说到哪里。

任一关键问题无法回答，状态保持待确认。
