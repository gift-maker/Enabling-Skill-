# 终稿图表交付协议

模型冻结后、论文写作前，每问必须建立一张已填写的图表任务卡。空白模板不能作为交付。

```text
问题：
该问冻结的主结论：
结果图：文件名、核心结论、源数据、图型理由：
决策/解释图：文件名、要解释的策略差异或切换条件、源数据、图型理由：
核心终稿图：文件名、为何它最值得进入 Nature 路线：
SciPilot 已完成：数据剖析 / 图表契约 / 自动审计 / 人工视觉回审：
Nature 已完成：源文件检查 / PDF字体 / 碰撞检查 / SVG或PDF导出：
图表支持的论文主张：
已知边界与不得从图中声称的结论：
```

## 强制交付

1. 每问至少一张结果图，直接支持该问的冻结主结论；
2. 优化、评价、决策、调度、路径、资源配置和方案选择题，另交付一张比较、敏感性、稳健性、状态流或策略切换图，解释为什么当前方案成立；
3. 每问从已有图中指定一张核心终稿图，完成 Nature Figure 的终稿增强和审计；
4. 每张正式图保存源数据、生成脚本、PNG、SVG、PDF、图注和审计结果；
5. 正文、摘要和结论只能引用任务卡中已登记且审计通过的图。

SciPilot 负责先判断结论、数据和图型；Nature Figure 负责已冻结核心图的出版级终稿与审计。二者不能被“直接调用 matplotlib 出一张 PNG”替代。
