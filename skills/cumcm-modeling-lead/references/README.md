## 使用时机

| 任务 | 读取 |
| --- | --- |
| 开始或推进阶段 | `阶段流程.md` 对应小节 + 项目 `AGENTS.md` 指定资料 |
| 选择模型或算法 | `模型选型树.md` + `算法索引.md` + 相关 `assets/*.md` |
| 写入 LaTeX 某章节 | `优秀论文写法指南.md` 对应章节；需要频率/案例时再读语料分析报告对应小节；`写作与图表规范.md` 和 `roles/论文手/章节模板.md` |
| 写、改或评摘要 | `摘要写作/摘要写作方法论.md`，按需读取其余摘要资料 |
| 绘图与配色 | `写作与图表规范.md` + `scripts/plot_style.py` + 相关绘图参考 |
| 图表自检 | `scripts/figure_audit.py` + `绘图参考/visual_review.md` |
| AI 使用声明/详情 PDF | `AI使用报告/README.md`、规范、模板、清单和审计脚本 |
| 终稿验收 | `质检清单.md` + `tools/latex/SKILL.md` + `scripts/paper_check.py` |

优秀论文资料是写作方法参考，不是官方规则；官方页数、格式、AI 声明和提交要求必须按当届原文核验。
