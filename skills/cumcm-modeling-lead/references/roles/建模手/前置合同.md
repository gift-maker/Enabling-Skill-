# 模型合同

模型合同是建模手控制本题逻辑的权威文件，在完整读题和数据预检后形成，并随实现证据更新。它不是 AI 的候选清单。

| 项目 | 必须回答的问题 |
|---|---|
| 任务与边界 | 本问描述、解释、预测、评价或决定什么？对象、时间、空间和忽略因素是什么？ |
| 事实分层 | 哪些是题目事实、数据发现、领域依据、建模假设、设计选择和未知项？ |
| 数学对象 | 集合、下标、输入、参数、决策变量、状态变量、随机变量和输出如何定义？ |
| 假设 | 为什么需要？证据是什么？取消后哪里变化？如何检验或做敏感性？ |
| 方程 | 每个数学关系的现实含义、来源、量纲和失效条件是什么？ |
| 目标 | 目标函数为什么代表现实目标？多目标之间如何权衡？ |
| 约束 | 每条约束来自哪里？属于硬/软、逐期/累计、个体/总体还是概率约束？ |
| 参数 | 参数如何取得，现有数据能否辨识？ |
| 候选 | 主方案、审计基线、强备选、降级保留和淘汰理由分别是什么？按题意选取的相关任务增益及其证据是什么？ |
| 实现 | 输入输出、求解算法、停止条件、状态码、降级使用方式和淘汰回退条件是什么？ |
| 验证 | 什么证据支持模型？什么结果会推翻模型？ |
| 递进结构 | 相较上一问是否新增离散决策、组合约束、资源配置、时序、风险或不确定性？是否需升级为决策/组合优化或二者串联？第三问优先检查但不预设 NP-hard。 |
| 跨问接口 | 输出如何进入后问？单位、索引和不确定性如何传递？ |
| 结论边界 | 结果允许怎样解释？哪些因果或外推结论不成立？ |
| 冻结条件 | 七项冻结条件是否满足？什么严重问题才允许解冻？新增验证是否可能改变主结论或最终决策？ |
| 建模手确认 | 建模手能否独立解释以上内容，状态为待确认、通过或退回修改？ |

每条核心方程和约束都要能回溯到题目、数据、领域依据或明确假设。模型合同变化后，受影响的代码、结果和后问必须重新审查。
