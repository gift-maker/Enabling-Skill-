# PDF attachment support

Read [TOOL_GUIDE.md](TOOL_GUIDE.md) before using this directory's scripts. Keep original attachments read-only, extract text and tables with page references, and visually inspect pages when layout affects meaning. Write derived files only to the problem project directory.
