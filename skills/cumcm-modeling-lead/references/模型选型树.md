# 模型选型树

本文件用于生成候选，不直接决定主模型。最终选择必须回到题目机制、数据结构、参数可辨识性、验证证据和计算预算。

## 第一层：任务目的

先区分：

- 描述：总结现状、结构或规律；
- 解释：分析因素关系，但除非设计和证据支持，不自动声称因果；
- 预测：对未见样本或未来进行估计；
- 评价：按明确定义的价值标准比较对象；
- 决策：在约束下选择行动；
- 机理：用守恒、传递、运动或演化规律描述系统。

一问可能包含多个阶段，例如“预测需求后优化库存”。为每个阶段定义清楚输入输出，不能把多个算法名称直接串联。

## 第二层：结构检查

在选择模型族前回答：

| 结构 | 必查问题 |
|---|---|
| 时间 | 是否有趋势、季节、滞后、结构突变或只能按时间验证？ |
| 空间/网络 | 是否存在邻接、距离、方向、连通或空间相关？ |
| 随机性 | 不确定性来自观测、参数、未来情景还是过程本身？ |
| 数据生成 | 样本是否独立？是否重复测量、分组、删失、选择偏差或类别不平衡？ |
| 变量 | 是观测量、潜变量、控制量、状态量还是决策量？ |
| 关系 | 有无守恒、单调、容量、先后、几何或物理边界？ |
| 参数 | 当前数据能否识别参数？模型自由度是否受样本支持？ |
| 结论 | 需要点估计、区间、排名、概率、方案还是机制解释？ |

## 第三层：模型族候选

| 核心结构 | 候选模型族 | 进入候选前的条件 |
|---|---|---|
| 连续或整数决策、明确约束 | LP/MIP、凸/非线性规划、动态规划、网络流、CP-SAT | 先写决策变量、目标、约束和变量域；先判断结构与规模 |
| 多目标冲突 | 分层优化、约束法、归一化加权、Pareto 方法 | 说明目标单位、冲突和偏好依据；做权重/折衷敏感性 |
| 纯时间序列 | 朴素基线、指数平滑、ARIMA、状态空间 | 按时间回测；检查季节、平稳性、结构突变和预测跨度 |
| 有解释变量的预测 | 线性/正则回归、树模型、核方法、适合数据量的时序模型 | 防泄漏；验证集调参；报告样本外误差与不确定性 |
| 多指标评价 | 直接指标法、PCA/因子、AHP、熵权、TOPSIS、DEA、模糊评价 | 先定义价值标准、指标方向、冗余和权重含义 |
| 分类或分群 | 逻辑回归、树模型、SVM、K-means、层次聚类、DBSCAN、混合模型 | 标签和样本代表性明确；聚类有稳定性和现实解释 |
| 网络与路径 | 最短路、匹配、生成树、网络流、TSP/VRP | 明确节点、边、方向、权重、连通和容量/时间窗 |
| 动态机理 | 代数/差分/微分方程、状态空间、Markov、系统动力学 | 明确状态、初边值、单位、守恒、参数估计和数值收敛 |
| 随机系统 | 概率模型、排队、蒙特卡洛、随机/鲁棒优化 | 分布或场景有依据；报告采样误差、风险指标和收敛 |

灰色预测只在小样本、序列结构和级比/误差检验均支持时进入候选；样本少本身不是采用理由。熵权反映当前数据的区分度，不等同于现实重要性。蒙特卡洛只在随机性、数值积分、风险传播或仿真验证确有作用时使用。

## 第四层：候选排序

通常提出 2–4 个可行模型族并统一比较：

1. 是否覆盖题目关键机制、目标和约束；
2. 假设是否与数据生成过程相容；
3. 参数能否由现有数据辨识；
4. 是否有无泄漏、可证伪的验证设计；
5. 能否在时限和算力内稳定实现；
6. 相对审计基线解决了什么真实缺陷；
7. 结果能否清楚解释，结论边界是否可控；
8. 失败时是否有可立即切换的路线。

优秀论文只用于扩展候选和学习验证方式。不得因为某模型常见、名称高级或曾出现在获奖论文中就提高排序。

## 求解方法与模型分离

遗传算法、粒子群、模拟退火等通常是求解方法，不是现实系统的数学模型。优化题先形成模型，再判断使用精确求解器、结构化算法、近似算法还是启发式。

启发式进入主方案前至少提供一种证据：小规模精确解对照、可证明上下界、已知基准、多起点或多随机种子稳定性、与成熟求解器的一致性检查。

## 题型匹配验证

- 预测/分类：时间或分层切分、样本外误差、残差/校准、基线比较、区间；
- 优化：全部约束回代、求解状态、上下界/最优性差距、小实例或多初值；
- 评价/排序：指标方向与冗余、权重含义、扰动后的排名稳定性；
- 机理/仿真：量纲、守恒、初边值、极端情形、步长/网格收敛；
- 统计推断：抽样与独立性、模型假设、效应量、区间和稳健性；
- 聚类/降维：初始化/抽样稳定性、解释方差或内部指标、实际可解释性。

阈值由题目精度、领域依据或预先声明的判据决定，不把 VIF、误差比例、样本量等经验数值写成普遍硬规则。
